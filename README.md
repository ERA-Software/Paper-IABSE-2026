# Paper-IABSE-2026
This repository accompagnies the paper "Designing structures for an uncertain future" presented at the IABSE Congress at Incheon in September 2026. It enables simple numerical investigations into the effect of uncertainty in future loads with non-stationary properties (e.g., due to climate change).
